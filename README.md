# DateStamp

Add the date to photos, entirely in the browser – nothing is uploaded. Static Astro site in seven languages, deployed to GitHub Pages.

```bash
npm install
npm run dev
```

See [CLAUDE.md](CLAUDE.md) for how it works, i18n/SEO and deployment.
